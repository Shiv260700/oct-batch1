Where rows live

Tables are stored in 8 KB pages

  • Rows are packed into pages of 8 KB
  • transactions: ~79 rows per page
  • 1,000,000 rows → 12,606 pages
  • PostgreSQL reads whole pages
  • This area is the heap: no special order

Speed is mostly about how many pages are read.

This is the most important idea in the workshop. Every optimisation later is a way to read fewer pages.

Part 2

Start PostgreSQL and load the data

Parts 2–4 in the lab guide

Start the server (choose one)

Docker Compose is the easiest

cd sql-advanced
docker compose up -d
docker logs advanced-sql-pg --tail 5
# look for: ready to accept connections
Other options

docker run … (see guide)

PostgreSQL already installed (15+)

The course folder is mounted inside the container at /workshop, so you don't need psql on your laptop.

Create your login and database

As the admin user, once

psql -h localhost -U postgres -d postgres

CREATE ROLE labuser WITH LOGIN PASSWORD 'LabOnly_ChangeMe123';
CREATE DATABASE paylab OWNER labuser;
\q
Run CREATE DATABASE on its own. It cannot run inside BEGIN … COMMIT.

Load the data

Always start psql in the course folder

cd sql-advanced
psql -h localhost -U labuser -d paylab
-- or: docker exec -it -w /workshop advanced-sql-pg psql -U labuser -d paylab

\i sql/00_setup.sql

Builds 3 tables in a few seconds. Same seed → identical data on every laptop.

The most common error: "sql/00_setup.sql: No such file". It means psql was started from another folder.
