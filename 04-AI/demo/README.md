# Log analyst demo (Apache + Java server logs)

**v1:** a chatbot over the logs · **v2:** the same chatbot with RAG · served with **FastAPI**.
Runs fully offline on a laptop: a small open-source model (`Qwen/Qwen2.5-0.5B-Instruct`) via Hugging Face `transformers`, and `all-MiniLM-L6-v2` for search. No Claude, no ChatGPT, no Ollama.

## Setup

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -c "from huggingface_hub import snapshot_download; snapshot_download('Qwen/Qwen2.5-0.5B-Instruct'); snapshot_download('sentence-transformers/all-MiniLM-L6-v2')"
.venv/bin/jupyter lab
```

Better answers (bigger, slower): `export MODEL_ID=Qwen/Qwen2.5-1.5B-Instruct`.

## Notebooks (run in order)

| Notebook | What it does |
|---|---|
| `00-make-data` | 3 days of Apache + Tomcat + Spring Boot logs with 5 planted incidents, the answer key, runbooks |
| `01-read-logs` | parse 5 formats into one table (stack traces joined); find every incident with pandas |
| `02-local-model` | load the local model; first answer; it hallucinates without the logs |
| `03-v1-chatbot` | v1: summary + newest problem lines + chat history |
| `04-v2-rag` | v2: chunk, embed, search, answer with sources or “Not found in the logs” |
| `05-evaluate` | 20 questions with known answers: v1 vs v2 |
| `06-fastapi` | start the API, call every endpoint, ingest a new log |

## API

```bash
uvicorn app.main:app --port 8000
curl localhost:8000/ready
curl -X POST localhost:8000/v1/chat -H 'content-type: application/json' -d '{"session_id":"me","message":"What is happening now?"}'
curl -X POST localhost:8000/v2/ask  -H 'content-type: application/json' -d '{"question":"Why did Apache return 502 on Oct 14?"}'
```

| Endpoint | Does |
|---|---|
| `GET /health` | alive |
| `GET /ready` | model + index loaded |
| `GET /stats` | requests, errors, top exceptions (no model) |
| `POST /v1/chat` | `{session_id, message}` → answer (keeps history) |
| `POST /v2/ask` | `{question, file?, since?, until?}` → answer + sources |
| `POST /v2/ingest` | `{name, text}` → new log lines become searchable |

Code: `logbot/` (make_data, parse, tools, llm, chat, rag, evaluate, prompts) and `app/main.py`. Notebooks are generated by `~/ai/labs/build_demo.py`.
